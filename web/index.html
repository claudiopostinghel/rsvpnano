Before You Click Install

  1. Use Chrome or Edge on macOS, Windows, Linux, or ChromeOS.
  2. Connect the device with a USB data cable.
  3. If the installer cannot connect, hold BOOT, tap reset or power-cycle, then try again.
  4. After flashing, place books on the SD card under /books.

The browser flasher is powered by ESP Web Tools and Web Serial. iOS Safari and Firefox do not currently support the required browser serial API.

Format SD Card

RSVP Nano requires a FAT32 SD card. Choose your operating system for the terminal commands.

  1. Find the SD card — open Terminal and run:
    diskutil list external physical
    This shows only external physical disks. The first line of the output contains the identifier you need, e.g. /dev/disk4.
  2. Format as FAT32 — replace the highlighted part with the identifier from step 1:
    sudo diskutil eraseDisk FAT32 RSVPNANO MBRFormat /dev/diskN
    Double-check the disk number before pressing Enter. This erases the entire disk. The volume will mount as RSVPNANO when finished.
  3. Create a /books folder on the newly formatted card and you’re ready to go.

Open Command Prompt as Administrator (right-click → Run as administrator) and run these commands one at a time:

  1. Open diskpart and list disks:
    diskpart
    list disk
    Identify the SD card by its size.
  2. Select and format — replace N with the correct disk number:
    select disk N
    clean
    create partition primary
    format fs=fat32 quick label=RSVPNANO
    assign
    exit
    Double-check the disk number. This erases the entire disk. The volume will appear as RSVPNANO when finished.
  3. Create a \books folder on the newly formatted card and you’re ready to go.
